# 14 测试、评测与验收设计

> 状态：draft  
> 范围：桌面端、后台、管理后台、模型、Agent、插件、连接器、安全与运维

## 1. 质量目标

- 核心流程在正常与主要失败场景下可恢复；
- 权限、数据边界和高风险确认不能被绕过；
- 模型用量与成本可追踪且可对账；
- Agent 生成的办公制品可打开、符合格式并有来源；
- 插件、连接器和更新故障不会扩散到整个客户端；
- 版本升级与数据库迁移可灰度和回滚；
- 模型质量不是“感觉不错”，而是使用版本化评测集验证。

## 10. 端到端 P0 场景

### E2E-001 登录和对话

前置：活动企业员工、授权逻辑模型、有效额度。

步骤：扫码 → 登录 → 新会话 → 发送问题 → 流式回复 → 查看用量 → 后台检索审计。

验收：用户、设备、逻辑/实际模型、Token、trace 关联一致。

### E2E-002 10 天闲置

使用可控时钟：最后有效活动 + 9d23h59m 仍可刷新；+10d 失效；后台心跳不延长；重登保留草稿。

### E2E-003 本地 Excel 到 PPT

选择三个文件 → 计划 → 确认 → 读取 → 汇总 → 生成 → 验证 → 预览。

注入失败：文件占用、Runner 崩溃、一个 Excel 损坏。验收失败后进度保留、恢复选项正确。

### E2E-004 MaxKB

创建/选择知识库 → 上传 → 处理 → 问答 → 引用 → 权限撤回。

撤回后打开引用必须被拒绝。

### E2E-005 内部数据只读查询

问题 → 指标匹配 → 行级权限 → 查询 → 图表/表格 → 来源/时间/口径 → 导出限制。

### E2E-006 插件发布和撤回

上传签名插件 → 扫描/审批 → canary → 客户端安装 → 调用 → 后台撤回 → 客户端拒绝新调用。

### E2E-007 客户端升级

发布 → canary → 下载/校验/安装 → 健康；注入启动失败 → 自动回滚 → 后台统计。

### E2E-008 邮件只读同步与 AI 草稿（P1）

后台分配邮件插件 → 用户完成独立邮箱授权 → 本地只读增量同步 → 搜索/线程 → 通过公司模型代理摘要 → 生成未发送草稿 → 查看用量和审计 → 后台撤回插件。

验收：服务器邮件状态不变；邮箱 secret 不进 SQLite/日志；模型数据边界和 Token 可追踪；撤回后不能继续同步或调用邮件 AI。

### E2E-009 单封邮件安全发送（P1）

编辑草稿 → prepare-send → 查看收件人/正文/附件/DLP → 确认 → send。注入内容修改、重复点击、网络超时、发送后客户端崩溃和服务端暂停发送。

验收：内容变化使确认失效；相同幂等键至多发送一次；结果未知进入对账而不是盲重发；后台暂停在规定时限内生效。

## 11. Agent 评测

### 11.1 评测集

每个 Skill 有版本化评测集：

### 11.2 指标

- plan validity；
- tool selection accuracy；
- unauthorized action rate（必须为 0）；
- task completion；
- recovery success；
- artifact validity；
- citation/source completeness；
- human correction effort；
- latency/cost；
- deterministic policy compliance。

### 11.3 制品评分

Word：可打开、结构、样式、模板、引用、修订。

Excel：可打开、公式、数值、工作表、图表、源数据一致。

PPT：可打开、幻灯片数、版式、溢出、模板、图表、引用。

PDF：可打开、页数、文本/图像、表格、OCR、无裁切。

自动验证 + 人工业务评分结合。不能只评模型文本。

## 18. 缺陷分级

| 等级 | 示例 |
|---|---|
| Blocker | 越权、数据泄漏、重复发送/写入、无法登录、全量更新失败 |
| Critical | 核心任务丢进度、错误计费、审计丢失、无法回滚 |
| Major | P0 功能失败、有安全替代路径但体验严重受损 |
| Minor | 非关键视觉/文案/边界问题 |

Blocker/Critical 未关闭或未经正式风险接受不得发布。
