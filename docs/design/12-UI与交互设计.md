# 12 桌面端与管理后台 UI/UX 设计

> 状态：draft  
> 当前桌面原型：[截图](../../artifacts/main-window.png)  
> 设计范围：Windows 桌面端 + Web 管理后台

## 1. 体验目标

- 普通员工无需理解模型供应商、MCP 或 Token 技术细节也能开始工作；
- 对话是入口，任务过程可见，制品是可验证结果；
- 模型、数据边界、工具、权限和用量始终能找到；
- 高风险操作说明“做什么、影响什么、发到哪里、能否恢复”；
- 长任务不阻塞主界面；
- 失败后给出恢复路径，不只显示错误码；
- 管理后台强调可治理和可解释，不以装饰性图表代替真实状态。

## 2. 设计语言

### 2.1 视觉方向

- 企业感、安静、清晰；
- 白色表面 + 浅蓝灰工作画布；
- 沉稳蓝作为主要动作和选中状态；
- 低强度边框替代大面积阴影；
- 有节制的圆角；
- 数据和任务界面优先保证密度、扫描效率和可访问性。

### 2.2 设计令牌

当前原型基线：

```yaml
color:
  canvas: "#F4F6FA"
  surface: "#FFFFFF"
  surface_alt: "#F8FAFC"
  primary: "#3168E0"
  primary_hover: "#2859C2"

  text: "#172033"
  text_secondary: "#5F6B7C"
  text_muted: "#8A94A6"
  border: "#E5E9F0"
  success: "#17845B"
  success_soft: "#E8F7F1"
  warning: "#A86612"
  warning_soft: "#FFF5E4"
  danger: "#C64545"

  control: 8
  panel: 12
  composer: 16

spacing:
  1: 4
  2: 8
  3: 12
  4: 16
  5: 20

```

正式实现应由共享 Token 驱动 PySide6 QSS 和管理后台 CSS 变量，但平台差异允许有明确映射。

### 2.3 字体

- Windows 中文：`Microsoft YaHei UI` 优先；
- UI 英文/数字可使用 Segoe UI，但必须保证中文回退；
- 正文 13–14 px；
- 表格 12–13 px；
- 页面标题 20–24 px；
- 控件文字不依赖系统默认继承；
- 行高至少为字号的 1.4 倍；
- 125%–200% DPI 实测。

### 2.4 图标

- 统一 1.7–2px 线性图标；
- 16/18/20/24 px 固定网格；
- 选中状态改变颜色，不随意切换填充风格；
- 危险、警告、成功不能只靠图标；
- 不用 Emoji 代替产品图标；
- 品牌标志与功能图标分离。

## 3. 桌面应用框架

```text
┌───────────────────────────────────────────────────────────────────────┐
│ 左侧导航 │ 顶部全局栏：搜索 / 用量 / 通知 / 帮助 / 用户              │
│          ├─────────────────────────────────────────┬─────────────────┤
│          │ 主工作区                                 │ 上下文/详情面板 │
│          │                                          │ 可按页面隐藏    │
│          ├─────────────────────────────────────────┴─────────────────┤
│          │ 当前页面状态/连接状态/安全提示                             │
└───────────────────────────────────────────────────────────────────────┘
```

### 3.1 左侧导航

1. 首页；
2. AI 对话；
3. 任务中心；
4. 文件与制品；
5. 知识库；
6. 邮件助手；
7. 企业应用；
8. 应用与插件；
9. 设置与帮助。

规则：

- 未授权模块不显示；
- 暂停/故障模块显示状态和原因；
- 任务中心显示待确认/失败的优先角标，不显示无意义总数；
- 缩小窗口时可折叠为图标栏，但 tooltip 和键盘访问保留；
- 当前页面、hover、focus、disabled 状态明确。

### 3.2 顶部全局栏

- 全局搜索/命令入口 `Ctrl+K`；
- 本月用量摘要；
- 通知；
- 帮助；
- 用户/组织/设备状态；
- 必要时展示“需要更新”“离线”“受限模式”。

全局栏不堆放所有模块快捷按钮。

## 4. 首次启动与登录

### 4.1 启动画面

- 品牌与版本；
- 初始化阶段：检查完整性、迁移、本地运行时、会话、版本；
- 超过 2 秒显示阶段；
- 超时显示诊断动作；
- 不显示技术堆栈。

### 4.2 扫码登录页

内容：

- 企业 AI 工作台名称；
- 企业微信二维码；
- “请使用企业微信扫码登录”；
- 二维码剩余时间/已过期刷新；
- 网络与隐私说明；
- 设备名称；
- 登录问题/诊断入口。

状态：正在生成、等待扫码、已扫码待确认、正在登录、拒绝、过期、网络错误、用户无权、设备不合规。

### 4.3 重登保护

会话过期时：

- 保留未发送草稿；
- 模态或全页重新扫码；
- 明确“连续 10 天未使用，需要重新登录”；
- 不显示“系统错误”；
- 重登后回到原上下文，但重新检查资源权限。

## 5. 首页

### 5.1 信息架构

- 问候与主输入；
- 继续最近任务；
- 等待确认；
- 最近对话；
- 常用 Skill/企业应用；
- 团队推荐模板；
- 系统通知/连接器状态（仅有意义时）；
- 用量提醒。

### 5.2 空状态

新用户只展示：

- 一个明显的“向 AI 描述工作”输入；
- 3–5 个公司批准的真实示例；
- 数据边界简明说明；
- 新手引导。

避免填充虚假统计卡片。

## 6. AI 对话

### 6.1 页面区域

- 会话标题/面包屑/最近更新时间；
- 消息流；
- 输入器；
- 右侧上下文面板；
- 底部连接与安全状态；
- 历史会话抽屉/独立列表。

### 6.2 消息展示

User Message：附件、文本、发送时间、编辑/重试（按规则）。

Assistant Message：

- 流式正文；
- 引用标记；
- 工具调用卡片；
- 思考/推理只显示经批准的摘要；
- 用量摘要；
- 复制、重试、反馈、升级任务；
- 错误和恢复动作。

### 6.3 输入器

- 多行输入；
- 附件；
- Skill/命令；
- 逻辑模型；
- 发送/停止；
- `Ctrl+Enter` 发送；
- 拖放文件；
- 超出限制时在发送前提示。

输入器上方不长期堆放几十个功能按钮；更多能力进入“+”菜单或 Skill 搜索。

### 6.4 上下文面板

固定可见信息：

- 当前逻辑模型；
- 处理位置/数据边界；
- 会话权限；
- 本轮文件、知识库、工具和系统；
- 用量；
- 引用；
- 清除上下文。

每个工具显示只读/可写范围和连接状态。

### 6.5 工具调用卡片

状态：建议、等待确认、运行中、成功、失败、已取消。

展示：

- 工具名称和版本友好名；
- 目的；
- 资源范围；
- 耗时；
- 结果摘要；
- 查看详情/审计引用；
- 失败恢复。

工具参数中的敏感值默认隐藏。

## 7. Agent 计划与权限

### 7.1 计划卡片

- 目标摘要；
- 预计步骤、时长、模型/资源成本；
- 每步动作和输出；
- 风险/确认点；
- 查看完整计划；
- 开始执行；
- 修改要求；
- 取消。

### 7.2 权限确认卡片

模板：

```text
任务请求：读取本地报表并创建新文件

读取范围：E:\部门月报\2026-07\ 下 3 个 .xlsx
创建位置：E:\部门月报\2026-07\输出\经营分析.pptx
数据发送到：公司内部模型代理 / 深度推理
有效范围：仅本任务
可恢复性：不会覆盖原文件

[拒绝] [修改范围] [允许本任务]
```

必须显示解析后的路径，不能只显示“允许访问文件”。

### 7.3 高风险确认

覆盖/删除/邮件发送/业务写入使用更强视觉和内容：

- 危险图标 + 明确动词；
- 影响数量；
- 前后值/收件人/目标系统；
- 可恢复性；
- 审批状态；
- 默认焦点不放在危险主按钮；
- 不用模糊“确定/取消”，使用“覆盖 1 个文件”等具体文案。

## 8. 任务中心

### 8.1 列表

筛选：运行中、等待确认、失败、已完成、已取消；任务类型；时间；本地/云端。

列表项：

- 标题；
- 状态；
- 当前步骤；
- 最近事件时间；
- 进度（仅有真实可计算进度时）；
- 风险/审批提示；
- 制品数量。

### 8.2 详情

- 目标和输入；
- 计划/步骤时间线；
- 当前步骤；
- 事件日志；
- 权限与审批；
- 用量；
- 制品；
- 暂停、继续、重试、修改、跳过、人工接管、终止。

### 8.3 失败状态

错误卡显示：

- 哪一步失败；
- 已完成内容是否保留；
- 原因（用户语言）；
- 技术错误引用/trace_id；
- 可用恢复动作；
- 每个动作的影响。

不将“重试”设为唯一选择。

## 9. 文件与制品

### 9.1 视图

- 最近制品；
- 按任务/类型/时间筛选；
- 预览；
- 来源文件；
- 版本和验证；
- 下载/打开所在目录；
- 保存到正式目录；
- 加入知识库；
- 提交业务系统（受控）。

### 9.2 Artifact 卡/行

- 文件名、类型和大小；
- 生成任务；
- 创建时间；
- 验证状态；
- 数据等级；
- 版本；
- 来源数量；
- 本地/云端位置。

### 9.3 预览

Office/PDF 预览不能替代最终可打开性验证。无法预览时提供安全的本地打开和明确提示。

## 10. 知识库

### 10.1 知识库列表

- 个人、团队、公司共享分区；
- 名称、说明、所有者、文档数、更新时间、权限；
- MaxKB 连接状态；
- 新建个人知识库（能力可用时）。

### 10.2 文档

状态：等待上传、上传中、解析中、索引中、可用、失败、删除中。

操作：上传、替换、重试、查看错误、删除、问答。

### 10.3 问答

- 明确当前知识库；
- 引用文档与片段；
- 打开原文时复核权限；
- 提交“引用不相关/答案错误”反馈；
- 显示知识库更新时间。

## 11. 邮件助手

### 11.1 信息架构

- 邮箱连接状态、账户授权和同步进度；
- 智能收件箱、未读、星标、需要回复、等待回复、待办和搜索；
- 会话、分类、标签、本地回收站和发件人档案；
- 邮件详情、附件状态、安全渲染和外部链接提示；
- 摘要、待办、批量归纳和本地报告；
- 草稿编辑、AI 回复建议和澄清；
- 发送确认、发送状态和结果对账；
- 自动化规则（后续、审批）。

采用与 SmartMail-Assistant 一致的三栏认知模型，但按工作台设计系统重建：左栏账户/视图/分类，中栏筛选和邮件列表，右栏邮件详情/附件/AI 结果/回复。顶部持续展示“本地只读镜像或服务端连接器”、最近同步和失败项；不整体嵌入 mail_tools 原主窗口。

### 11.2 AI 内容边界

- 原邮件与 AI 摘要视觉区分；
- 草稿标明 AI 生成；
- 外部内容风险提示不过度打扰；
- 邮件中的“指令”不能显示为平台建议；
- 附件送模型前确认数据边界。

### 11.3 账户与同步

- 普通用户只看到管理员允许的 OAuth、Microsoft 365、腾讯企业邮箱或标准 IMAP 类型；
- 企微应用邮箱由管理员创建后分配，不显示 Corp Secret 输入框；
- 企业微信扫码登录成功不等于邮箱已授权；
- 同步进度按账户显示连接、发现、下载、解析、索引和结果；
- 单封失败提供重试、跳过、修改账户、导出诊断和暂停，不锁死整个队列；
- 明确“本地删除不会删除服务器邮件”。

### 11.4 附件与发送

- 附件显示文件名、大小、来源、下载、扫描和本地状态；
- 打开、送模型、上传知识库、导出和转发分别确认；
- prepare-send 页面展示 From/To/Cc/Bcc、主题、正文、附件哈希/扫描、外部联系人、DLP 和 AI 标识；
- 用户确认后若内容变化，页面显示“确认已失效，需要重新检查”；
- 超时显示“发送结果待确认”，提供查询、等待、人工核对，不提供默认再次发送按钮；
- 首期不展示 Agent 自动发送、批量发送和服务器删除入口。

详细页面、状态和迁移计划见 [邮件模块与 mail_tools 复用设计](16-邮件模块与mail_tools复用设计.md)。

## 12. 企业应用

- 应用目录按部门授权；
- 显示只读/可写、数据范围、负责人和状态；
- 每个应用提供真实示例问题；
- 数据回答展示指标口径、时间、筛选和来源；
- 图表可切换表格；
- 导出前展示行数和敏感字段处理；
- 写操作进入独立准备/审批/执行页面。

## 13. 应用与插件

普通用户视图：

- 已授权；
- 可申请；
- 管理员暂停；
- 版本与更新时间；
- 权限；
- 数据边界；
- 启用/禁用个人偏好（不可绕过后台撤回）；
- 健康和诊断。

权限升级时展示差异，而不是重新显示全部条款。

## 14. 设置与诊断

### 14.1 设置

- 外观；
- 语言；
- 通知；
- 默认下载/制品位置；
- 本地授权工作区；
- 快捷键；
- 隐私和缓存；
- 设备和会话；
- 关于与版本。

服务端 URL、证书和公司策略默认只读。

### 14.2 诊断

- 客户端、Runner、API 和插件版本；
- 服务连接状态；
- 最近错误引用；
- 本地数据库/Runner 健康；
- 检查更新；
- 重启 Runner；
- 导出脱敏诊断包；
- 不显示完整 Token/Key。

## 15. 通知

优先级：

- Critical：强制升级、账户/安全、业务写失败；
- Action required：审批、任务等待用户；
- Warning：配额、连接器异常、任务部分失败；
- Informational：任务完成、知识库索引完成；
- Silent：普通同步和健康状态。

Toast 不承载必须阅读的长内容；所有重要通知进入通知中心。

## 16. 空、加载、错误、无权限

必须区分：

- Empty：没有数据，给下一步；
- Loading：显示骨架/进度；
- Offline：网络问题，说明可继续的本地能力；
- Error：系统失败，提供重试和 trace_id；
- Forbidden：没有权限，显示申请/负责人；
- Disabled：管理员暂停，显示原因和预计恢复；
- Unsupported：客户端版本/能力不兼容；
- Expired：登录、审批或链接过期。

## 17. 管理后台框架

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 品牌 / 环境              全局搜索        告警  帮助  管理员          │
├───────────────┬─────────────────────────────────────────────────────┤
│ 概览          │ 页面标题 / 面包屑 / 说明             主要操作        │
│ 组织与访问    ├─────────────────────────────────────────────────────┤
│ AI 能力       │ 筛选栏 / 保存的视图                                  │
│ 扩展能力      ├─────────────────────────────────────────────────────┤
│ 治理与运维    │ 表格 / 详情 / 差异 / 时间线                          │
│               │                                                     │
└───────────────┴─────────────────────────────────────────────────────┘
```

管理后台以表格、筛选、差异和详情为主，不把所有数据转成卡片。

## 18. 管理后台页面

### 18.1 概览

第一屏：

- 核心服务状态；
- 今日模型请求/成功率/P95/成本；
- 运行中和失败任务；
- 待审批；
- 高风险事件；
- 连接器异常；
- 旧客户端比例。

每个指标可下钻，标明时间范围、口径和刷新时间。

### 18.2 用户与部门

表格列：姓名、部门、状态、角色、客户端版本、最近活动、当月用量、风险。

详情抽屉/页面：基本信息、权限来源、模型/插件、设备、会话、额度、审计。

批量操作先显示受影响人数，禁用等危险操作需要原因。

### 18.3 角色与策略

- 角色权限矩阵；
- 策略列表和状态；
- 可视条件编辑器 + JSON 高级视图；
- 策略模拟；
- 影响分析；
- 版本差异；
- 发布和回滚。

### 18.4 模型与路由

- 逻辑模型表；
- 实际模型和能力矩阵；
- 路由优先级；
- 数据边界；
- 健康/延迟/成本；
- 测试控制台；
- 评测；
- 发布历史。

路由编辑不做不可理解的自由流程图；候选顺序、条件和降级采用结构化表单。

### 18.5 用量与预算

- 时间/部门/用户/模型/模块筛选；
- Token 和非 Token 单位分开；
- 成本趋势；
- 额度规则；
- 阈值和告警；
- 临时申请；
- 估算/对账差异。

### 18.6 插件与连接器

- 版本、签名、扫描、权限差异和兼容；
- 发布环和安装成功率；
- 撤回；
- Connector 实例、凭据引用、健康、目标和权限；
- 不在 UI 显示可复制的完整 Secret。

### 18.7 审计

- 强筛选表格；
- 事件时间线；
- 决策解释；
- 元数据/正文访问分权；
- 保存查询；
- 导出审批、进度和短期下载。

### 18.8 客户端版本

- 版本状态；
- 签名/扫描；
- 发布环；
- 设备分布；
- 成功、失败、回滚；
- 暂停/继续/强制截止时间；
- 兼容矩阵。

## 19. 表格与批量操作

- 列可调整但关键标识不隐藏；
- 默认按最近变化排序；
- 分页/虚拟化；
- 筛选可保存；
- 导出显示当前筛选；
- 批量操作显示精确影响；
- 批量危险操作二次确认和原因；
- 全选明确是“当前页”还是“全部筛选结果”；
- 长操作异步进入任务中心。

## 20. 表单

- Label 永不只依赖 placeholder；
- 必填、格式和业务错误就地显示；
- Secret 输入只允许写入/替换，读取时显示掩码；
- 高级 JSON 编辑同时提供 Schema 校验；
- 离开未保存表单提示；
- 发布与保存草稿分开；
- 影响生产的变更展示 diff、影响范围和原因。

## 21. 文案规范

### 21.1 错误

结构：发生什么 → 当前影响 → 用户能做什么 → 诊断引用。

好：

> MaxKB 暂时无法处理该文件。文件已保留，尚未加入知识库。你可以重试、替换文件或将错误编号 KB-... 发给管理员。

避免：

> Internal Server Error 500。

### 21.2 权限

说明资源和原因：

> 你没有“财务明细导出”权限。你仍可查看汇总指标，或向财务数据负责人申请临时导出权限。

### 21.3 AI 不确定性

- “AI 生成内容，请核对”只作为基线提示；
- 数据回答附口径、来源和时间；
- 无引用时明确“未使用企业知识库”；
- 估算用量显示“估算”，不显示虚假精确费用。

## 22. 键盘与可访问性

桌面建议：

- `Ctrl+K` 全局搜索；
- `Ctrl+N` 新对话；
- `Ctrl+Enter` 发送；
- `Esc` 关闭非破坏性浮层/停止当前组合；
- `Ctrl+,` 设置；
- Tab 顺序符合视觉顺序；
- 所有图标按钮有 accessible name 和 tooltip；
- 焦点环明显；
- 不用颜色单独表达状态；
- 支持系统对比度和文本缩放测试。

## 23. 响应式与窗口

桌面首发建议：

- 推荐 1440×900；
- 最低工作尺寸由测试确定，目标不低于 1120×700；
- 宽度不足时先折叠右侧上下文，再折叠导航；
- 任务详情和审计表格可全屏；
- 多显示器和 DPI 切换不丢失窗口；
- 窗口位置恢复前验证仍在可见屏幕。

管理后台支持公司标准桌面浏览器；移动端只保证关键告警/审批可读，复杂策略编辑不承诺移动体验。

## 24. UI 验收清单

- 所有 P0 页面有 loading/empty/error/forbidden/offline；
- 所有危险操作使用具体动词和影响范围；
- 当前模型、边界和工具可见；
- 长任务不阻塞其他页面；
- 失败提供至少一种安全恢复；
- 125%–200% DPI、最低尺寸无主要裁切；
- 键盘可完成核心路径；
- 颜色对比和状态冗余通过检查；
- 管理表格支持真实筛选、下钻和影响分析；
- 原型中的中文字体、导航、计划卡和上下文面板保持一致。
